# Ethics and Consent

This project is built for interviewers, examiners, mentors, and hiring panels who have permission to record or analyze the session.

The application should not be used as a hidden interview-taking assistant, a proctoring bypass, or a tool for undisclosed capture.

Required product defaults:

- Capture starts only after consent is marked.
- Recording status is visible.
- Overlay is an interviewer workspace, not a stealth UI.
- Exports should show what was captured, when, and by which source.
- Cloud AI calls should be optional and clearly labeled.

Recommended pre-session script:

> I use an assistant to transcribe the discussion and keep rubric notes. It does not make hiring decisions. Are you comfortable with me using it during this session?
